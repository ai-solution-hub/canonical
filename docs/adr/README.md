# Architecture Decision Records

Platform decisions live here, numbered from 0001 and never renumbered. Admission is platform
operational or architectural **by definition** — product strategy, commercial framing and
client-specific rulings are PRD amendments, not ADRs.

Each file carries a one-line `Crosswalk: DR-NNN` naming the source ruling in the legacy
decision register. That register is closed: it remains in the private docs repo as history, is
not extended, and rulings re-authored here were written fresh rather than copied.

Format: H1 title, crosswalk line, then **Context**, **Decision**, **Alternatives considered**,
**Consequences**. Supersede a ruling with a new ADR that says so; never rewrite an old one.
